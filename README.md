# Инструкция и настройки для модерации ВКонтакте (VK Mini Apps / VK Games / VK Play)

## 1. Настройки экрана в кабинете разработчика (dev.vk.com)

При создании и настройке игры во вкладке **«Настройки» / «Платформы»**:

### Десктопная версия (Web / Компьютеры):
- **Тип приложения:** Web / Iframe
- **URL для десктопа (Iframe URL):** `https://maectro.github.io/starorusskaya-usadba/`
- **Ширина:** `1000 px` (рекомендуемая), поддерживает динамическую ширину от 800 до 100% ширины контейнера ВК.
- **Высота:** `650 px` (рекомендуемая), адаптивный layout автоматически подстраивается под высоту без появления полос прокрутки.

### Мобильная версия (Mobile Web / Android / iOS):
- **URL для мобильной версии:** `https://maectro.github.io/starorusskaya-usadba/`
- **Ориентация экрана:** `Портретная (Portrait)` / `Адаптивная (Fluid)`
- **Viewport:** `width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`
- **Safe Area Insets:** В коде стилей `style.css` прописаны `env(safe-area-inset-top)` в `#top-bar` и `env(safe-area-inset-bottom)` в `#bottom-nav`. Элементы управления гарантированно не перекрываются «чёлкой», «островком» (Dynamic Island) или нижней системной полосой жестов.

## 2. Текст для поля «Описание основных сценариев» для модераторов ВК

Скопируйте следующий текст в консоль модерации:

```text
Описание основных сценариев и механик для модерации ВКонтакте:

1. СТАРТ И ОСНОВНОЙ ЭКРАН (СЕЛО):
- При первом запуске игра открывает главное село Усадьбы. Реклама на старте отключена (правило ВК).
- В шапке отображаются текущие ресурсы (дерево, золото, смола, богатырская энергия) и кнопка звука 🔊/🔇.
- Игрок может нажать на любое здание (Кузница, Мельница, Изба, Терем) для просмотра информации и улучшения за ресурсы.

2. МАТЧ-3 ГЕЙМПЛЕЙ («В ПОХОД»):
- Нажатие на кнопку «⚔️ В Поход» переводит на экран уровня «три в ряд».
- Игрок перемещает соседние фишки кликом или свайпом, собирая ряды от 3 одинаковых элементов.
- 4 фишки в ряд создают Руну Молнии, 5 фишек — Солнцеворот или Бомбу.
- При завершении уровня (победа или поражение) открывается модальное окно результата.

3. ПРОВЕРКА РЕКЛАМЫ (VKWebAppShowNativeAds):
- Межстраничная реклама (interstitial): вызывается строго после завершения уровня при нажатии кнопки «Продолжить» на экране результатов. Срабатывает только при соблюдении жесткого кулдауна (не чаще одного раза в 65 секунд).
- Реклама за вознаграждение (rewarded):
  1) Кнопка «📺 Удвоить Награду (x2)» на экране победы — удваивает золото и дерево за уровень.
  2) Кнопка «+5 Ходов (📺)» при исчерпании ходов на уровне — добавляет 5 ходов.
  3) Кнопка «Крутить за просмотр» во вкладке «Колесо Велеса».
  4) Кнопка «Гостинец купцов» во вкладке «Ярмарка».
  Все rewarded-интеграции запускаются исключительно по прямому клику игрока.

4. ПРОВЕРКА ЗВУКА (п. 2.2.5 Правил модерации ВК):
- В верхнем правом углу доступна кнопка 🔊/🔇, полностью отключающая аудио.
- При сворачивании приложения или переключении вкладки события 'visibilitychange' и VK Bridge события 'VKWebAppViewHide' / 'VKWebAppViewRestore' моментально глушат и корректно возобновляют фоновую музыку и звуки.
- Перед показом любого рекламного ролика аудио моментально глушится, а после закрытия рекламы восстанавливается (только если звук не был выключен игроком вручную).

5. СОХРАНЕНИЕ ПРОГРЕССА:
- Все заработанные ресурсы, прокачанные уровни построек, открытые богатыри и рекорды сохраняются в облаке ВК через VKWebAppStorageSet с синхронизацией в локальное хранилище браузера (localStorage).
```

## 3. Развёртывание на GitHub Pages (HTTPS без CORS и VPN)

1. Создайте публичный репозиторий на [GitHub](https://github.com/new), например `slavic-manor-vk`.
2. Свяжите локальный репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш_логин>/slavic-manor-vk.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings -> Pages**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
   - Нажмите **Save**.
4. Через 1-2 минуты игра будет доступна по защищённому адресу:
   `https://<ваш_логин>.github.io/slavic-manor-vk/`
   Этот адрес стабильно открывается в РФ без VPN, не блокируется, поддерживает HTTPS и безопасный фрейминг ВК.
